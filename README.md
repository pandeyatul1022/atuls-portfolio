## 📖 Overview

Welcome to the official repository for **Atul Pandey's Personal Portfolio Website**. This project showcases full-stack web development projects, technical skills, professional experience, education, and an interactive contact interface.

It features modern glassmorphism aesthetic elements, smooth scroll-driven animations, real-time dark/light theme switching, and custom domain-lock security mechanics.

---

## ✨ Key Features

- 🌓 **Dynamic Dark / Light Mode**: Seamless theme toggling with preference persistence.
- 📱 **Fully Responsive Layout**: Mobile-first design optimized across desktop, tablet, and smartphone screens.
- 🎨 **Modern Glassmorphism & Animations**: Powered by custom CSS design tokens and **AOS (Animate On Scroll)** library.
- 📂 **Interactive Sections**:
  - **Hero**: Introduction with availability status indicator and quick actions.
  - **About**: Personal profile summary and core focus areas.
  - **Skills**: Categorized skill tags (Frontend, Backend, Tools, Databases).
  - **Projects**: Visual cards detailing full-stack applications with demo links.
  - **Experience & Education**: Timeline view of career background and qualifications.
  - **Contact Form**: Direct contact form integration.
- 📄 **Resume Download**: Direct access to downloadable PDF resume (`Atul_Pandey.pdf`).
- 🛡️ **Anti-Piracy & Domain-Lock Controller**: Integrated client-side security engine (`security.js`) preventing unauthorized public mirror hosting.

---

## 🛠️ Tech Stack

- **Frontend Core**: HTML5, Vanilla CSS3 (Custom CSS Tokens), JavaScript (ES6+)
- **UI Framework**: Bootstrap 5
- **Icons & Typography**: Bootstrap Icons, Google Fonts (*Inter* & *Space Grotesk*)
- **Scroll Animations**: AOS Library (Animate On Scroll)
- **Deployment**: GitHub Pages

## 💻 Local Setup & Development

You are welcome to clone and run this portfolio locally on your machine for personal study or educational evaluation.

### Prerequisites
- Any modern web browser (Google Chrome, Mozilla Firefox, Microsoft Edge, Safari)
- Optional: Code Editor (VS Code) with *Live Server* extension or Git.

### Steps to Run Locally

1. **Clone the Repository:**
   ```bash
   git clone https://github.com/pandeyatul1022/atuls-portfolio.git
   cd atuls-portfolio
   ```

2. **Launch the Project:**
   - **Option A (Direct File):** Double-click `index.html` to open it in your browser.
   - **Option B (VS Code Live Server):** Open the project folder in VS Code, right-click `index.html`, and click **Open with Live Server**.

## 🛡️ Security & Anti-Piracy Protection

This repository includes an integrated **Security Controller** (`assets/js/security.js`).

- **Local Host Study Allowed**: You can run and inspect this code on `localhost` or local file previews without any restriction.
- **Unauthorized Public Hosting Locked**: If this codebase is hosted or copied to an unauthorized public web domain (Vercel, Netlify, Github Pages mirror, custom domain), the security engine automatically locks the UI and sends real-time forensic notifications to the owner.

For details on security alerts and DMCA enforcement, refer to [DMCA_TAKEDOWN_GUIDE.md](./DMCA_TAKEDOWN_GUIDE.md).
